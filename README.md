# QR-меню и сайты для ресторанов Баку

Лендинг услуги и демо QR-меню вымышленного ресторана «Nar Bağı».

- **Лендинг (AZ/RU):** https://ravenfield228.github.io/baku-qr-menu/
- **Демо-меню (AZ/RU/EN):** https://ravenfield228.github.io/baku-qr-menu/demo/
  (язык можно задать ссылкой: `?lang=az`, `?lang=ru`, `?lang=en`)

## Что умеет демо-меню
- Три языка, выбор запоминается; по умолчанию берётся язык телефона.
- Категории с липкой навигацией и подсветкой текущего раздела.
- Поиск сразу по всем трём языкам.
- Карточка блюда с фото, порцией и ценой; блюда без фото выглядят аккуратно.
- Метки: вегетарианское, хит, новинка, острое.
- Часы работы, адрес на карте, звонок, Instagram, Wi-Fi с копированием пароля.
- Тёмная тема, адаптив 375 / 768 / 1280 px, без фреймворков и сборки.

## Структура
```
index.html            лендинг услуги
assets/               стили и скрипт лендинга, QR-код на демо, OG-картинка
demo/index.html       страница меню
demo/menu-data.js     ДАННЫЕ МЕНЮ — единственный файл, который меняется под клиента
demo/menu.css, menu.js
demo/img/             фото блюд (webp, 600×450)
favicon.svg
```

## Как сделать меню для клиента
1. Скопировать папку `demo/` в новый репозиторий клиента.
2. В `demo/menu-data.js` заменить всё, что помечено `[ЗАМЕНИТЬ]`: название, адрес, телефон, Wi-Fi, блюда, цены. Поставить `demo: false`.
3. Положить фото клиента в `demo/img/` (webp, ~600×450, до 100 КБ).
4. Включить GitHub Pages и сгенерировать QR-код на итоговый адрес.

## Что заменить на лендинге перед отправкой
Всё помечено `[ЗАМЕНИТЬ]` в `index.html`: бренд, цены трёх тарифов, срок изготовления, период бесплатных правок, хостинг, номер WhatsApp (`wa.me/994XXXXXXXXX`), Instagram.

## Локальный запуск
Любой статический сервер из корня репозитория, например:
```
npx serve .
```
